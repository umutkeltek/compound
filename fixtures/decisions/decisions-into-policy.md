# Reversible local doc edits run without approval

A decision remade from scratch every session — "should the agent ask before editing a local
markdown doc?" — becomes a standing policy. Reversible, local, non-destructive documentation edits
are pre-authorized through a StandingGrant; anything that leaves that envelope (external, public,
destructive, financial, security) still escalates through the policy gate.
