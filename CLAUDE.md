## Absolutes (this file is always in context; AGENTS.md is not)
Four rules where the first wrong move is expensive, so they must reach you even if you never open AGENTS.md.
Each names the failure it prevents; the rest of the contract is behind the pointer above.

- **Execution workspace resolves `--workspace` → `git_delivery` → `cwd`, and never `COMPOUND_HOME`.** There is
  no home fallback by design: a code-editing harness pointed at the home directory edits state and config
  instead of the project, and the edits look like successful work.
- **Mint the `ratt_*` RunAttempt before any side effect; terminalize it on every path.** A run left `pending`
  or `running` has no recovery path — the sweep is audit-only and will not close it for you.
- **`compound work advance --execute` is the only governed execution.** `harness run` is an ungoverned manual
  record (it warns, and reports `governed: false`). When the governed path is blocked, stop and say so; do not
  produce a similar-looking artifact by the ungoverned route.
- **This repo is destined to be public.** Never write a personal path, credential, account, real-product, or
  private-tool name into a tracked file, including comments — `docs_private/` is gitignored and never shipped.
  A clean `redact` scan is the push gate (standing grant — no per-push confirmation; force-push and history
  rewrites still ask).
